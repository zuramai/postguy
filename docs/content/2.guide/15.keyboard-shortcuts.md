One command registry drives the menus, the command palette, the keyboard shortcuts, the `Settings › Shortcuts` page and the `command` operation of the [UI control channel](/reference/ui-control-channel). On Windows and Linux `Cmd` is shown and typed as `Ctrl`. The one exception is full screen: `Ctrl+Cmd+F` on macOS, `F11` elsewhere.

::note
Shortcuts cannot be changed. `Settings › Shortcuts` lists them read-only, and Postguy does not check shortcuts for conflicts.
::

## Command palette

Press `Cmd/Ctrl+K` (when no text field has focus) or click the search button in the header.

- Type to filter: a case-insensitive fuzzy match, so letters only have to appear in order.
- Without a prefix the list shows matching workspace items first (open tabs, up to 10 recently closed tabs, collections, folders, requests and environments), then commands.
- Start the query with `>` to list commands only.
- At most 12 results are shown. `Up` and `Down` move, `Enter` runs the selected row, `Esc` closes the palette.
- A command row's hint reads `Group · shortcut`.

## When a shortcut works

Registry shortcuts are ignored while a text field has keyboard focus, with these exceptions that always fire: the zoom commands, full screen, every `Window` command (`Minimize`, `Close window`, placement) and `Quit`. The `Edit` shortcuts are handled by the text field itself.

## Shortcuts outside the registry

| Keys | Where | Action |
|---|---|---|
| `Cmd/Ctrl+S` | Request builder | Save the request. |
| `Cmd/Ctrl+Enter` | Request builder | Send the request. |
| `Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z` | Anywhere without a focused text field | Undo or redo the last rename or move in the sidebar tree. |
| `Cmd/Ctrl+D` | Code editors | Add the next occurrence of the selection as another cursor. |
| `Cmd/Ctrl+A` | Code editors | Select all. |
| `Up`, `Down` | Sidebar | Move the focused row. |
| `Right`, `Left` | Sidebar | Expand or collapse a folder, collection, or a request's examples. |
| `Enter` | Sidebar | Open the focused row. |
| `F2` | Sidebar | Rename the focused row. |
| `Cmd/Ctrl+C`, `Cmd/Ctrl+X`, `Cmd/Ctrl+V` | Sidebar | Copy, cut, paste items. A paste on a collection or folder pastes inside it; on a request, into its collection. |
| `Delete` | Sidebar | Delete the focused item. On a History row it removes that history entry. |
| `Cmd/Ctrl`-click, `Shift`-click | Sidebar | Multi-select. |
| Middle-click a tab | Tab strip | Close the tab. |
| Drag a tab | Tab strip | Reorder tabs. |
| `Esc` | Palette, dialogs, inline rename | Close or cancel. |

Sidebar keys work only when no text field has focus and a sidebar row is focused. See [Collections](/guide/collections) for what copy, cut, paste and delete do.

## Run a command from outside the window

The command ids (for example `request.send`, `view.sidebar`, `runner.open`) can be run through the control channel with `postguy-cli ui --control FILE command ID`. See [UI control channel](/reference/ui-control-channel).
