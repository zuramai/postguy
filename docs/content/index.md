#title
Postguy

#description
The offline, native API client for HTTP, gRPC and WebSocket.

Works like Postman, and reads Bruno collections. No account, no sync, no telemetry.

#title
What you get

#features
  :::u-page-card
  ---
  title: Offline by design
  description: No account, cloud sync, telemetry or update check. The network is used only when you send a request or start an action.
  icon: i-lucide-wifi-off
  ---
  :::

  :::u-page-card
  ---
  title: Native on every desktop
  description: One Rust and egui app for macOS, Windows, Linux and FreeBSD. No browser engine and no web build.
  icon: i-lucide-monitor
  ---
  :::

  :::u-page-card
  ---
  title: Collections and environments
  description: Folders, requests, variables, globals and secrets, stored as plain JSON files in a workspace folder you choose.
  icon: i-lucide-folder-tree
  ---
  :::

  :::u-page-card
  ---
  title: Scripts and tests
  description: Pre-request and post-response scripts in a sandboxed QuickJS engine. Supports the pm, pg and Bruno-style APIs.
  icon: i-lucide-flask-conical
  ---
  :::

  :::u-page-card
  ---
  title: Collection runner
  description: Run a collection with data files and iterations, in the app or from the CLI. Reports in CLI, JSON, JUnit, HTML, CSV, XLSX and PDF.
  icon: i-lucide-play
  ---
  :::

  :::u-page-card
  ---
  title: Headless automation
  description: postguy-cli uses the same engine as the app, so scripts and agents can do what you do by hand.
  icon: i-lucide-terminal
  ---
  :::
::
