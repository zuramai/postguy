title: Build from source
description: Build the Postguy desktop app and the postguy-cli binary with Cargo on macOS, Windows, Linux and FreeBSD.
---

## Toolchain

- Stable Rust 1.95 or newer, installed with [rustup](https://rustup.rs). The floor is the `rust-version` in the root `Cargo.toml`, which is what egui 0.36 needs. CI builds with the stable channel.
- Edition 2024.
- No Node, no web or WebAssembly target, and no font to download: the only embedded font is Poppins, plus egui's default fonts.

## Build and run

```sh
git clone https://github.com/zuramai/postguy.git
cd postguy
cargo build --release -p postguy -p postguy-cli
```

The binaries are `target/release/postguy` (the desktop app) and `target/release/postguy-cli` (the headless CLI); on Windows they end in `.exe`. To run the app straight from the source tree with a workspace of your choice:

```sh
cargo run -p postguy -- --workspace ~/postguy-workspace
```

For day-to-day work, `cargo build -p postguy` and `cargo build -p postguy-cli` build the debug versions.

## Prerequisites per OS

::tabs
  :::tabs-item{label="Linux"}
  The window system and graphics libraries are needed to build. CI installs these Debian/Ubuntu packages:

  ```sh
  sudo apt-get install -y --no-install-recommends \
    libxkbcommon-dev libwayland-dev libx11-dev libxrandr-dev libxi-dev \
    libgl1-mesa-dev
  ```

  CI also installs `libgtk-3-dev`. It is optional: the app's file dialogs use `xdg-desktop-portal`, not GTK, so it is not required to build or run Postguy. At run time, X11 or Wayland, xkbcommon and EGL/GL are loaded dynamically, and `xdg-desktop-portal` provides the file dialogs.

  For other distributions, install the equivalent development packages for xkbcommon, Wayland, X11 (including Xrandr and Xi) and Mesa GL.
  :::

  :::tabs-item{label="macOS"}
  Install the Xcode Command Line Tools:

  ```sh
  xcode-select --install
  ```

  The release build targets macOS 11.0 or newer. A native menu bar is used on macOS only.
  :::

  :::tabs-item{label="Windows"}
  Install the MSVC build tools: Visual Studio Build Tools with the "Desktop development with C++" workload. The supported targets are `x86_64-pc-windows-msvc`, `i686-pc-windows-msvc` and `aarch64-pc-windows-msvc`.

  The 32-bit (`x86`) target also needs libclang: the script engine (`rquickjs`) has no pre-generated bindings for it, so `bindgen` generates them (`crates/script/Cargo.toml`). Install LLVM and, if the build cannot find it, set `LIBCLANG_PATH` to its `bin` folder.
  :::

  :::tabs-item{label="FreeBSD"}
  FreeBSD is built from source only. The repository does not name FreeBSD packages, so treat this as guidance: it is community-tested, and you should open an issue if a package name differs.

  ```sh
  sudo pkg install rust llvm
  ```

  - `llvm` provides libclang. The script engine has no pre-generated bindings on FreeBSD, so `bindgen` generates them (`crates/script/Cargo.toml`). If the build cannot find libclang, set `LIBCLANG_PATH`.
  - Install the X11, Wayland, Mesa and xkbcommon libraries and development headers for your desktop, the same set as on Linux.
  - If the `rust` package is older than 1.95, install the toolchain with rustup instead.
  - File dialogs use `xdg-desktop-portal`, as on Linux.
  :::
::
