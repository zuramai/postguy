#title
Postguy

#description
The offline, native API client for HTTP, gRPC and WebSocket.

A Postman-like API client that works completely offline, with Bruno collection support. No account, no sync, no telemetry.

#title
What you get

#features
  :::u-page-card
  ---
  title: Offline by design
  description: No account, no cloud sync, no telemetry, no update check. The network is used only when you send a request or run an action you started.
  icon: i-lucide-wifi-off
  ---
  :::

  :::u-page-card
  ---
  title: Native on every desktop
  description: One Rust and egui binary for macOS, Windows, Linux and FreeBSD. No browser engine, no web build.
  icon: i-lucide-monitor
  ---
  :::

  :::u-page-card
  ---
  title: Collections and environments
  description: Folders, requests, variables, globals and secret values, stored as plain JSON files in a workspace folder you choose.
  icon: i-lucide-folder-tree
  ---
  :::

  :::u-page-card
  ---
  title: Scripts and tests
  description: Pre-request and post-response scripts in a sandboxed QuickJS engine, with the pm, pg and Bruno-style APIs.
  icon: i-lucide-flask-conical
  ---
  :::

  :::u-page-card
  ---
  title: Collection runner
  description: Run a collection with data files and iterations in the app, or from the command line with CLI, JSON, JUnit, HTML, CSV, XLSX and PDF reports.
  icon: i-lucide-play
  ---
  :::

  :::u-page-card
  ---
  title: Headless automation
  description: postguy-cli drives the same engine as the UI, so scripts and agents can do what you do by hand.
  icon: i-lucide-terminal
  ---
  :::
::
